How BitWise works

ONE NUMBER, FOUR LANGUAGES

The four modes are not different calculators — they are four ways of writing the same number. Type 255 in DEC, then swipe: it becomes FF in HEX, 377 in OCT and 1111 1111 in BIN. The value never changes, only the notation. The small rows under the display always show the other three at once.

DEC — BASE 10

Everyday numbers, the ones you count with. Use it when the number is just a quantity: money, distances, IDs.

Try: type a Unix timestamp like 1784073600 — BitWise recognizes it and shows the actual date.

HEX — BASE 16

Compact shorthand for binary: one hex digit is exactly four bits. That's why programmers use it for colors, memory addresses and raw data.

Try: type FF5733 — that's a web color, and BitWise shows you the actual shade. Type 48 and it tells you that's the letter H in ASCII.

OCT — BASE 8

Groups bits three at a time. Its most famous job today is Unix file permissions.

Try: type 755 in OCT — BitWise decodes it to rwxr-xr-x: owner can read/write/execute, everyone else read/execute. That's what chmod 755 means.

BIN — BASE 2

The machine's native tongue: every digit is one bit, on or off. Perfect for flags, masks and understanding what the bitwise keys (AND, OR, XOR, shifts) actually do.

Try: type 1010, then press << 1 = and watch every bit slide one place left in the grid — that's why shifting left doubles a number.

THE BIT GRID & BYTES

Every square is one bit — tap any square to flip it and watch all four notations update. The chevron swaps between keypad and inspector: expand to give the bit grid the whole screen, collapse to get the keys back — picking Bits, Bytes or FIELD opens it automatically. FIELD lets you tap two bits to read out just that slice, like a hardware register field. The Bytes view shows the same value carved into bytes with hex, decimal and ASCII — flip BE/LE to see both memory orderings, and COPY puts the full hex word on your clipboard. The Float view decodes the same bits as IEEE 754: sign, exponent and mantissa color-coded — type 3F800000 in HEX and see it become float 1.0. Mid-calculation (e.g. after typing 8 −) a small line like 8 − ⇄ appears above the big number — tap it to swap the two operands, turning 8−3 into 3−8.

STD — EVERYDAY MODE

A normal decimal calculator with a professional touch: a history tape above the keys remembers your last 40 calculations even after closing the app — tap any line to bring its result back. The trash button in the header wipes the tape — it asks for a second tap (turning red) so one stray touch can't erase everything. Memory keys work like a classic desk calculator: M+/M− accumulate, MR recalls (an M badge shows when something is stored), MC clears. √ and 1/x apply instantly; xⁿ opens a power picker (x² to x⁵, or xʸ… to type any exponent, even 0.5 or negative). Everything lands on the tape. Percent is smart too: 200 + 10 % means 200 plus 10 percent of 200, so = gives 220.

NOT SURE WHAT A KEY DOES?

Long-press it. Function keys like AND, XOR, RoL, MOD, %, M+ and friends pop up a short explanation with an example — without pressing the key. Digits and obvious keys stay quiet.

COPYING RESULTS

Tap the big number to copy it — in HEX/OCT/BIN it copies with the proper prefix (0xFF, 0o377, 0b11111111) so it pastes straight into code. Long-press any square in the bit grid to see that bit's weight without toggling it.

POWER GESTURES

Long-press AC to undo a clear and get your number back. Press = again to repeat the last operation (5 + 3 = = = → 8, 11, 14). Drag across the bit grid to paint a whole run of bits on or off in one stroke. Long-press a conversion row to copy the value in that base; tap an insight pill to copy what it found (the IP, the color, the chmod string). Long-press a tape entry to delete just that line.

GESTURES

Swipe left/right on the display to change base (HEX → DEC → OCT → BIN) — the keypad reshapes itself so you only ever see keys that exist in that base. Swipe left/right on the keypad to flip between the programmer and standard calculators — the small PRG/STD dots at the top show where you are. Tap any small conversion row to jump straight to that base. Word-size chips (8–128) set how many bits the number lives in; SIGNED switches to two's-complement so negative numbers make sense.

INSTALL AS AN APP

Opened from its website, BitWise shows an install button in the header — tap it and it lands on your home screen as a fullscreen app with its own icon. After the first visit it works with no connection at all.

Updates arrive by themselves: when a new version has been published, a bar appears at the bottom — tap Update and the new version loads. The build id at the bottom of this guide tells you which version you are on.
